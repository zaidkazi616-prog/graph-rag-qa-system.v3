Overview
An advanced AI Question-Answering system that allows users to upload any PDF document. It features a Smart Router that detects user intent: it can calculate word counts instantly, generate full document summaries using Llama 3.1, or answer specific questions using the Graph RAG pipeline.

What is New in Version 3
Smart Intent Routing: The AI detects if you want a summary, a word count, or a specific detail.
Word Count Engine: Instantly calculates and returns the exact word count of the PDF.
Full Document Summarization: Uses Llama 3.1 to read the entire document and generate a human-like summary or explain what the document is about.
Graph RAG for Specifics: Still uses the Knowledge Graph for highly specific questions to ensure accuracy.
